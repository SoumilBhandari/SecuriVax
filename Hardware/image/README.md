# Hardware image inventory

The current drawings in this folder belong to **SecuriVax 102**. They document the enclosure and assembly; there are currently no Prototype 101 images here.

## SecuriVax 102 drawings

| File                                 | What it shows                                                                          |
| ------------------------------------ | -------------------------------------------------------------------------------------- |
| `Animate Box Issometric Drawing.png` | Exploded isometric assembly with enclosure, PCB, sensors, buttons, battery, and reader |
| `Animate Box Drawing.png`            | Exploded assembly with numbered component callouts                                     |
| `Box view Drawing.png`               | Top, front, rear, left, and right orthographic views                                   |
| `LOW CAVER Drawing.png`              | Lower-cover drawing with dimensions and section view                                   |
| `LOW CAVER Issometric Drawing.png`   | Isometric view of the lower enclosure cover                                            |
| `TOP COVER Issometric Drawing.png`   | Isometric view of the top cover                                                        |
| `TOP COVER Drawing.png`              | Top-cover drawing with orthographic views                                              |
| `Measurements Box Drawing.png`       | Overall enclosure dimensions: 70 mm x 30 mm x 17 mm                                    |

The drawings use the original filenames so they remain traceable to the supplied CAD exports. The spelling `Issometric` and `CAVER` is retained in filenames for compatibility.
