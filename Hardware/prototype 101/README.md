# prototype 101

The first node: an ESP32 devkit, a sensor and a USB power bank in a lunchbox,
with an ice cube standing in for the cold chain. No enclosure — everything is
loose in the box.

This is what the bench demo was built on, and what
[docs/hardware.md](../../docs/hardware.md) describes wiring up.

Superseded by [`../SecuriVax (102)`](<../SecuriVax (102)>), which puts the same
electronics in a sealed case sized around a LiPo cell.
