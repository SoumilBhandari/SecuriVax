# Evals

Generated by `cd backend && .venv/bin/python -m evals.run`. Each suite checks one part of the system
against a target; the targets are what we consider good enough to demo and to trust.

Every suite runs on synthetic data: simulated sensors and boxes, generated label
photos, a simulated node on a lossy link. The carrier twin has not yet seen a
real cooler, and the VVM reader has not yet seen real label photos; drop real
`stageN_*.jpg` photos in a folder and run `python -m evals.calibrate_vvm --photos DIR`.

**8 of 8 suites pass.**
